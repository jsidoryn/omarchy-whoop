# Security Policy

Please report security vulnerabilities through [GitHub private vulnerability reporting](https://github.com/jsidoryn/omarchy-whoop/security/advisories/new).

Do not include WHOOP Client Secrets, OAuth tokens, keyring contents, or health information in a public issue. If private vulnerability reporting is unavailable, email [jason@katalyst.com.au](mailto:jason@katalyst.com.au).

The current supported release line is `0.1.x`. Security fixes will be documented in the repository and included in the next tagged release.
